## Notes
- Scene files (.unity) must be created and saved from **inside Unity Editor**
- After creating each scene, add it to **File → Build Settings** in the correct order
- Naming convention: kebab-case (see CONVENTIONS.md)
- The test-level scene is the Sprint 1 sandbox — all systems are tested there
